# MAMTIL.KMMA

Портал Сектора развития государственного языка КГМА им. И. К. Ахунбаева.

## Разделы
- Библиотека образцов документов «Үлгүлөр» (DOCX/PDF, предпросмотр, KY/RU)
- Проверенный медицинский словарь (KY/RU/LA, импорт и экспорт Excel/CSV)
- Нормативно-правовые документы (НПА)
- Академический ИИ-переводчик (`KY ↔ RU`)
- Визуальная административная панель (`/admin`)

## Переменные окружения (Vercel)
- `NEXT_PUBLIC_SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_ANON_KEY`
- `GEMINI_API_KEY` (опционально, для ИИ-переводчика)
